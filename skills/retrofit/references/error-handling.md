# 错误处理

## 调查材料不足

```
调查阶段未找到足以支撑基线的材料（README / CHANGELOG / 提交信息 / issue 均无有效陈述）。

请选择：
1. 指定我漏掉的材料位置（文档 / wiki / issue 链接 / 其他仓库）
2. 直接建立基线 —— 「项目目的与边界」整节标 `未知`，其余节按代码信号出草案
3. 我也不清楚，先不建基线

选 2 不是失败：一份诚实标出未知的基线，价值高于一份看着完整但一半是猜的。
它告诉接手者「自己不知道什么」，而这恰恰是接手时最需要的信息。
```

## 项目无任何文档

```
当前项目未检测到任何文档。这在接手存量项目时很常见。

基线仍然可以建立 —— 它本来就不依赖旧文档：
- 「代码外部的硬约束」「项目目的与边界」→ 问你，问不出就标 `未知`
- 「已知未知」→ 恰恰是这种项目最有价值的一节
- 「证据冲突」→ 无旧文档则本节为空

是否开始？
```

## 迁移冲突

```
检测到迁移冲突：

| 冲突项 | 说明 | 建议 |
|--------|------|------|
| 编号重复 | F-001 已存在 | 重新分配编号 |
| 文件覆盖 | 03-test-cases.md 已存在 | 备份后覆盖 |

请确认处理方式。
```
