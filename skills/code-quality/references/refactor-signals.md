# 重构信号与流程

> 配合 [SKILL.md](../SKILL.md) 使用。系统性重构工作流（范围分析 + 测试门禁）用 `/refactor`。

## 重构触发条件（Code Smells）

### 必须重构

> 指标与重构方向**均见 [SKILL.md 核心阈值表](../SKILL.md#核心阈值表)**（该表已含「超最大值的重构方向」列）——超最大值即必须重构。本节不镜像。

### 建议重构

| 问题 | 描述 | 重构方向 |
|------|------|----------|
| 特性依恋 | 频繁访问其他类数据 | 移动方法 |
| 数据泥团 | 多个参数总是一起出现 | 提取类 |
| 霰弹式修改 | 一个改动影响多处 | 集中逻辑 |
| 平行继承 | 每次加子类要加配套类 | 合并层次 |

## 重构流程

```
1. 确保测试覆盖
   │
   ├── 有测试 → 继续
   └── 无测试 → 先补充测试
   │
   ▼
2. 小步重构
   │
   ├── 每次只改一件事
   ├── 每步都能运行
   └── 每步都运行测试
   │
   ▼
3. 验证行为不变
   │
   ├── 测试全部通过
   └── 手动验证关键路径
   │
   ▼
4. 提交代码
```

## 范围约束

- [ ] 大范围重构需要分阶段进行

## 风险评估

| 风险等级 | 条件 | 策略 |
|----------|------|------|
| 低 | 有完善测试、改动局部 | 直接重构 |
| 中 | 部分测试、影响多处 | 先补测试 |
| 高 | 无测试、核心逻辑 | 逐步添加测试后重构 |
