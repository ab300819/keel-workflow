# 设计方案草案模板（初始 + 增量）

> 配合 `/ms-system-design` 使用。在分析完成、写入文档前展示草案并使用 AskUserQuestion 等待用户确认。

## 快速档边界自查块（必答，嵌入草案顶部）

快速档下 L1~L4 分层交互合并为一次展示，**以下块必须完整填写**（不允许空着或整体"跳过"），否则视为质量门退化：

```markdown
## 快速档边界自查

### L1~L4 边界校验

| 层级 | 产出章节 | 边界检查 | 结果 |
|------|---------|---------|------|
| L1 架构 | §2 + §1 | 无模块级细节泄漏到架构图 | ✅/⚠️ |
| L2 模块 | §4 | 职责单一；"依赖接口引用"列格式合规 | ✅/⚠️ |
| L3 接口行为 | §5 | 无越界反例（7 类，见 design-boundary-guide.md） | ✅/⚠️ |
| L4 数据模型 | §8 | 仅写调用方不可见细节；可观察约束已在 §5 错误契约 | ✅/⚠️ |

### 越界反例自查（决策 4 清单，L3 完成时强制）

七类越界反例的完整判据见 [design-boundary-guide.md](design-boundary-guide.md)，L3 完成时逐条自查。

### 遗留 ⏳ 项汇总
（列出所有标 `⏳` 的占位；若无则填"无"）
```
