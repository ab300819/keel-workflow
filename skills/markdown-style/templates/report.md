## 修改结果

以下两种情况二选一填写，取决于**目标文件自身**在事务开始前的 git 状态（见设计方案 §6.1）。判据逐文件判，**不看整仓 `git status`**——`git checkout -- <file>` 只回滚该文件，仓库里其他文件脏不脏与回滚成本无关。机械判据：`git ls-files --error-unmatch <file>`（已跟踪）且 `git diff --quiet -- <file>`（自身无未提交改动）。
