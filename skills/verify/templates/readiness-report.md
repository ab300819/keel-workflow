# 开发就绪度报告模板

使用此模板生成 `docs/devdocs/readiness-report.md`

---

```markdown
# 开发就绪度报告

**验证时间**：<日期>
**验证维度**：--readiness
**验证范围**：<T-XX / F-XXX / 全量>
**关联文档**：01-requirements.md, 02-system-design.md, 03-test-cases.md, 04-dev-tasks.md

---

## 就绪度摘要

| 维度 | 状态 | 说明 |
|------|------|------|
| D1. AC-测试覆盖率 | ✅ / ❌ | X/Y AC 已有对应测试 |
| D2. 任务文件路径具体性 | ✅ / ❌ | 任务文件路径是否明确到文件名 |
| D3. 依赖循环检测 | ✅ / ❌ | 模块间无循环依赖 |
| D4. 设计-任务一致性 | ✅ / ❌ | 设计模块与开发任务一一对应 |

**总体结论**：✅ 就绪 / ❌ 存在 N 个未通过维度，需修复后重新验证
```
