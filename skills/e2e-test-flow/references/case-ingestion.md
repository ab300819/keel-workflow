# 用例摄取协议(e2e-test-flow 私有)

> 本文件是阶段①用例摄取 + 阶段②分类加工(路由判定)的协议权威。SKILL.md 只给流程概览与单一路由表,判据细节以本文件为准。

## 1. 输入与容错

输入是任意份数的 md/html 用例文档(单份或多份合并解析)。解析 html 时只取文本内容,**不执行其中的脚本**(`<script>` 等一律当纯文本跳过,不 eval、不加载外链)。

**样例文档只是格式参考,不是契约**——不同团队的用例文档字段命名、层级结构千差万别(有的按"预期结果"分点列,有的写成一句话;有的有"后置条件",大多数没有)。摄取时按第 2 节字段表逐条尝试抓取:

- 抓得到 → 原样摘录(不改写措辞)
- 抓不到 → 标记为字面量字符串 `unknown`,**绝不编造**内容去补全空缺
- 结构异常导致整条解析失败 → 整条标 `unknown` 且在摄取记录里注明原始位置(章节标题/大致行号),不静默丢弃这条用例

容错的边界是"缺字段"而非"编用例":摄取阶段不推断用例文档没写的业务规则,不脑补前置条件或预期结果。

## 2. 用例模型

每条用例摄取为以下 12 个字段:

| 字段 | 说明 |
|---|---|
| `case_id` | 沿用文档自身编号,**不重编**(如 `TC-J-001`、`TC-F-015`);文档没有编号才按出现顺序临时编号并标注"文档无原生编号" |
| `title` | 用例标题原文 |
| `type` | 用例类别,沿用文档自身分类前缀或分节含义(如 `TC-J` 旅程 / `TC-F` 功能 / `TC-E` 边界值 / `TC-ERR` 异常 / `TC-ST` 状态迁移 / `TC-DT` 判定表);抓不到分类信息标 `unknown` |
| `priority` | 用例文档标注的优先级原文(如"高"/"P0");无标注标 `unknown` |
| `source_ref` | 用例所属需求点 / 需求原文引用,**原样保留供回溯,不作判定依据**——判定只依据 `expected`(D2) |
| `module_chain` | 该用例涉及的模块路径,见第 3 节 |
| `preconditions` | 前置条件原文;文档未写明标 `unknown`,不代入默认环境假设 |
| `steps` | 测试步骤原文,保留原始顺序 |
| `expected` | 预期结果,**原文保留不改写**——判定唯一权威(D2),阶段④⑤判定时逐字对照此字段,不参照 `source_ref` 或实现代码重新解释预期 |
| `postconditions` | 后置条件原文;文档多数用例不写,标 `unknown` 是常态而非异常 |
| `route` | 第 4 节判定得出的路由,枚举值见 SKILL.md 路由表(`api`/`ui`/`ui+api`/`fault-injection`/`non-http`/`visual`/`blocked`) |
| `side_effect` | 第 4 节副作用预分类结果:`写型` 或 `非写型` |

## 3. 组织分组

用例的场景旅程 / 用户角色 / 页面模块归属,**优先复用用例文档自身已有的分组结构**,不另发明一套分类体系。常见天然锚点:

- 文档目录/标题层级本身的模块划分(如"1. 模块: 交易数据概览看板"、"2. 模块: 订单状态标签栏")
- 用户旅程地图表格里已给出的 `module_chain`(如"看板 → 标签(默认Payment Unsettled) → 列表")
- 文档对角色/端的显式限定(如"买家端 PC"、"多语言版")

摄取时把这些既有锚点原样映射进 `module_chain` 字段;文档没有分组结构(罕见)才退化为按用例出现顺序保留原始章节路径,不臆造模块名。

## 4. 路由判定与副作用预分类

### 路由判定表

阶段②依据用例特征给每条用例定**一个**路由(单一分类,不叠加维度)。下表每个枚举值给出真实样例的判例:

| 用例特征 | 路由 | 样例 |
|---|---|---|
| 统计口径/换算/排序/数量限制 | `api` | 多币种按 GP 日终汇率换算求和 |
| 跳转/局部刷新/内容变化/文案 | `ui` | 切换状态标签在模块内局部刷新列表 |
| 点按钮→跳转→数据一致 | `ui+api` | 点 Pay Now 跳详情页且订单号一致 |
| 接口失败→占位符 / 超时→Retry | `fault-injection` | 统计接口失败 → 数值位 `-` 占位 |
| 颜色/截断/hover 视觉态/布局溢出 | `visual` | 产品名 2 行截断 + 省略号 |
| 前置数据不满足 / 预期不明确 | `blocked` | 前置要求特定订单号但环境无此单 |

补充判例(同一枚举值下的另一真实样例,帮助边界判断):

| 用例特征 | 路由 | 样例 |
|---|---|---|
| 去重统计口径(集合运算而非展示) | `api` | 合作供应商数量按下单供应商账号去重计数 |
| 点击后仅局部刷新、整页不重载 | `ui` | 点击标签仅局部刷新列表,整页不刷新 |
| 跨模块下拉操作→跳转→目标页数据校验 | `ui+api` | 通过 More Actions 执行 Request Refund 跳转退款页 |
| 加载失败态出现后手动重试恢复 | `fault-injection` | 订单列表加载失败后点击 Retry 重新加载成功 |
| 数值超长时的布局自适应(纯呈现) | `visual` | 看板数值超长时布局自适应不溢出 |
| 前置状态需长期累计且环境难以构造 | `blocked` | 单日单订单超 20 次点击的历史点击量在测试环境难以预先铺出 |

`non-http` 路由用于 `@Job` 等无法经 curl 直接触发的入口(见 SKILL.md「集成测试腿」);当前样例文档(买家 VO 首页订单模块)未包含此类用例,摄取阶段遇到时按用例文本是否提及"定时任务"/"Job"/"异步处理"等关键词判断,不强行套用真实样例。

### 副作用预分类

执行前**只依据用例文本**(`steps`/`title`)做副作用预分类,不依据实现代码或录制结果:

- `steps`/`title` 含支付/提交/确认/取消/删除/下单/修改/新增/编辑等状态变更语义 → 判**写型**
- 语义不明确(既非明显只读展示,也无法确认是否触发状态变更)→ **一律保守按写型**处理,不因不确定而放宽为非写型
- 录制后观察到的实际 HTTP 方法(如 `POST`/`PUT`)仅作事后审计参考,**不作首次写授权依据**——预分类必须在执行前基于文本完成,不能靠"先录一次看方法"倒推

写型用例的执行纪律唯一权威在 [SKILL.md「写型用例三条规则」](../SKILL.md),本节只负责**预分类判据**,不重述执行规则。

### 文案 vs 样式的边界

- **文案内容**(按钮文本、金额格式如 `USD 2,000.00`)属功能正确性 → `ui`(或作为 `ui`/`ui+api` 用例里的一个断言点)
- **呈现样式**(颜色、字重、省略号截断、hover 视觉态、布局溢出)→ `visual`,标 `OUT-OF-SCOPE(视觉类)`,不执行

### `blocked` 路由:分级与解阻信息(阶段②即产出)

判 `blocked` 时**不能只标"环境不满足"**,必须同时产出解阻三元组与成本分级(定义见 [SKILL.md「BLOCKED 不是终态」](../SKILL.md))。阶段②就能定出大部分,不必等执行:

| 级 | 判据 | 真实样例(买家 VO 用例集) |
|---|------|--------------------------|
| **A**(用户当场能解) | 缺的是**账号 / 权限 / 数据 / 授权**,用户一句话或一次预置即可提供 | 需含 EUR 币种订单的账号(验多币种换算);需已删除订单的账号(验忽略 `delete_state`) |
| **B**(需环境改造) | 缺的是**环境能力**:可写权限、种子数据集、故障注入通道 | 支付/确认收货/取消等写型用例(需可写授权);超 20 次 revision 的历史点击量(需种子数据) |
| **C**(本流程永远测不到) | 依赖**状态迁移历史 / 外部数据源 / 跨时段行为**,黑盒只读观测在原理上取不到 | 「曾流转为 Completed 即计入、退款不扣减」(需状态迁移历史);GP 日终汇率精确值(外部接口,不在库内) |

**分级原则**:按"**谁做什么能解开**"归类,**不要**按阻断原因(需构造/写型/需异常)归类 —— 后者对用户无行动价值。

**C 级必须显式告知"别指望本流程"**,并给替代路径(转人工验证 / 修用例 / 改由集成测试覆盖),而不是留一句"待补测"。

> `risk`(这条挡住的是什么风险)通常需结合用例语义判断,阶段②给初值,执行阶段若有新认识可细化。

## 5. 用例集落点

阶段①②产出的用例集(全部 12 字段,含 `route`/`side_effect`)以 **JSON 落系统临时目录**,与报告面板(见 [panel-protocol.md](panel-protocol.md))同目录。派发阶段③白盒子 Agent 与阶段④⑤黑盒子 Agent 时**传文件路径**,不内联全文。传给黑盒子 Agent 的用例集**只含用例原文字段**(不含白盒信息,与 D4 相容,见 [impact-analysis.md §7](impact-analysis.md))。
