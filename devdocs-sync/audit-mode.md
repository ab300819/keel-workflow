# 追溯健康度检查 (--audit)

> 检测编号体系的完整性，防止"Sync Debt（文档维护债）"积累。

## 检查项目

| 检查项 | 检查内容 | 健康标准 |
|--------|----------|----------|
| **AC 覆盖** | 每个 AC-XXX 是否被测试覆盖 | 100% AC 有关联测试 |
| **F 任务闭环** | 每个 F-XXX 是否有任务，任务是否完成 | 所有 F 有任务且闭环 |
| **INS 转化** | 已确认的 INS-XXX 是否转化为 F | 确认的 INS 已转化 |
| **孤立编号** | 是否存在无关联的测试/任务 | 无孤立编号 |

## 健康度报告格式

```markdown
# 追溯健康度报告

**检查时间**：2024-XX-XX
**健康度评分**：85%

## AC 覆盖检查

| AC 编号 | 关联测试 | 状态 |
|---------|----------|------|
| AC-001 | UT-001, E2E-001 | ✅ 已覆盖 |
| AC-002 | UT-002 | ✅ 已覆盖 |
| AC-003 | - | ❌ **缺失** |

**覆盖率**：2/3 (67%)

## F 任务闭环检查

| F 编号 | 功能名称 | 关联任务 | 完成状态 |
|--------|----------|----------|----------|
| F-001 | 用户注册 | T-01, T-02, T-03 | ✅ 3/3 完成 |
| F-002 | 用户登录 | T-04, T-05 | ⏳ 1/2 进行中 |
| F-003 | 密码重置 | - | ❌ **无任务** |

**闭环率**：1/3 (33%)

## INS 转化检查

| INS 编号 | 状态 | 转化目标 | 检查结果 |
|----------|------|----------|----------|
| INS-001 | ✅ 已确认 | F-003 | ✅ 已转化 |
| INS-002 | ❌ 已拒绝 | - | ✅ 已记录原因 |
| INS-003 | ⏳ 待确认 | - | ⚠️ 待处理 |

## 孤立编号检查

| 编号 | 类型 | 问题 |
|------|------|------|
| UT-015 | 单元测试 | ⚠️ 未关联任何 AC |
| T-12 | 任务 | ⚠️ 未关联任何 F |

## 修复建议

1. **AC-003 缺失测试**
   - 建议：补充 UT 或 IT 测试用例
   - 运行：`/devdocs-test-cases` 补充

2. **F-003 无任务**
   - 建议：拆分开发任务
   - 运行：`/devdocs-dev-tasks`

3. **孤立编号 UT-015**
   - 建议：指定关联的 AC 编号
   - 或：确认是否为无效测试
```

## 使用场景

```bash
# 定期健康检查（建议每 Sprint 结束时执行）
/devdocs-sync --audit

# 完整同步时自动包含健康度摘要
/devdocs-sync
# → 在进度报告末尾显示健康度评分
```
